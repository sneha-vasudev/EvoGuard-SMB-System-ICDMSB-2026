HOW TO USE THIS CODE
================================================================================

1. DOWNLOAD & SETUP:
   git clone https://github.com/yourusername/evoguard-smb.git
   cd evoguard-smb
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt

2. PREPARE DATA:
   Place CSV files in database/ folder:
   - Enron.csv
   - TREC-07.csv
   - Nazario_5.csv
   - complaints_processed.csv
   - Bitext_Sample_Customer_Service_Training.csv
   - Email Analysis Dataset.csv

3. RUN TRAINING:
   python main.py --train-neat --generations 50

4. FIND RESULTS:
   outputs/
   ├── models/neat_model.pkl
   ├── quarantine/
   ├── priority/
   ├── crm/
   └── summary_report_*.txt
